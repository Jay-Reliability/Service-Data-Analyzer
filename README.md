# SVC Data Pro-Analyzer Excel V3.0 ⚡

LG전자 / 삼성전자 신뢰성 분석 체계 및 Weibull, Log-Normal, Kaplan-Meier 통계 모델을 웹 브라우저에서 분석할 수 있는 대시보드입니다.

## 기능 안내
- 서비스(SVC) 및 생산수량 Excel 데이터 자동 파싱
- 순간/누적 고장 건수 및 고장률(Hazard, CDF) 피벗 테이블 생성
- 신뢰성 분포 적합도 검증(Anderson-Darling) 및 최적 모델 추천
- Matplotlib 스타일 인터랙티브 차트(Pan, Zoom, Point 호버 주석) 지원
- 피벗 및 분석 결과 CSV 내보내기 지원
